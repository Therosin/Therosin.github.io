## Overview

This is my personal portfolio website showcasing my projects and blog posts. Built with modern web technologies for optimal performance and developer experience.

## Technologies Used

- **Astro**: Static site generator for fast builds and great SEO
- **TypeScript**: Type-safe JavaScript for better development experience
- **SCSS**: Enhanced CSS with variables and nesting
- **Markdown**: Content management with MDX support

## Features

- Responsive design that works on all devices
- Dark/light theme support
- Blog with pagination
- Project showcase
- Fast loading times with static generation
- SEO optimized with meta tags

## Development

The site is built with a focus on performance and maintainability. Content is managed through Markdown files, making it easy to add new blog posts and projects without touching code.

## Deployment

Hosted on GitHub Pages with automatic deployment through GitHub Actions.
